# Filatrix ERP Web 财务模块设计

> **历史资料（2026-09-16 标记）：**独立财务模块已经退出当前产品范围。本文仅保留早期决策轨迹，不得用于恢复财务菜单、会计凭证、应收应付台账或资金流程。当前销售开票/回款与采购收票/付款只按蓝图和事实模型定义为订单下的轻量商务跟进。

> 本文服从 `erp-web-prototype-blueprint.md` 与 `erp-web-business-fact-model.md`，用于冻结财务模块本轮页面职责和业务口径。

## 1. 模块目标

财务模块负责记录开票、收票、应收、应付及真实资金事件，不替代销售、采购、仓库或质量状态。每张财务单据都能回看来源业务；每次收付款都独立留痕，不用一个主状态覆盖全部事实。

## 2. 页面边界

| 页面 | 页面职责 | 主要动作 |
| --- | --- | --- |
| 销售发票 | 核对销售订单行、保存发票、确认开票、查看红字与退款关系 | 新建、保存、确认开票、红冲、打印 |
| 采购发票 | 核对物料采购正式入库，或核对资产采购验收与供应商发票 | 新建、保存、来源匹配、确认收票、打印 |
| 应收账款 | 展示来源销售发票、应收总额、已收和未收 | 登记收款、查看收款记录 |
| 应付账款 | 展示来源采购发票、应付总额、已付和未付 | 登记付款、暂缓提示、查看付款记录 |

应收和应付由发票确认后生成，不提供脱离来源业务的“新建应收/应付”。列表不放重复操作列，整行进入详情后执行高风险动作。

## 3. 状态拆分

| 对象 | 生命周期 | 独立进度 |
| --- | --- | --- |
| 销售发票 | 待开票、已开票、已红冲 | 未收款、部分收款、已收款、已冲销 |
| 采购发票 | 待收票、已收票、已冲销 | 未付款、部分付款、已付款 |
| 应收账款 | 待收款、部分收款、已收款、已冲销 | 由有效收款事件累计 |
| 应付账款 | 待付款、部分付款、已付款、暂缓付款、已冲销 | 由有效付款事件累计 |

列表状态列同时展示生命周期和结算进度，但不把两者合并为一个可编辑主状态。销售订单和采购订单只读取财务事实聚合进度，不由财务动作直接改写为“已完成”。

## 4. 核心流程

### 4.1 销售侧

`销售订单 → 销售发票 → 确认开票 → 应收账款 → 一笔或多笔收款 → 结清`

- 发票行稳定关联销售订单行，并按有效发票累计校验数量和金额。
- 收款允许小于未收金额；累计金额达到应收总额才进入已收款。
- 每笔收款保存日期、方式、账户、资金凭证号、经办人、备注和幂等键。
- 红冲追加红字发票和反向承接；已收金额形成退款义务，不删除原发票或收款历史。

### 4.2 采购侧

`物料采购 → 采购收货 → 质量放行 → 正式入库 → 采购发票 → 三单匹配 → 应付账款 → 一笔或多笔付款 → 结清`

- 采购发票必须来源于采购收货，不直接以采购订单代替入库凭证。
- 确认收票前同时核对采购订单行、当前入库单正式入库数量和本次发票行。
- 同一采购订单分批入库时，各发票只占用对应入库单的可开票数量；其他入库批次不得混算。
- 待质检、质检冻结或尚未正式入库的收货不能确认收票。
- 付款支持部分金额、重复请求幂等和独立付款记录；超付由服务端阻断。

资产采购使用独立来源链：

`资产采购 → 到货 → 验收通过 → 采购发票 → 资产采购匹配 → 应付账款 → 一笔或多笔付款 → 结清`

- 资产采购不生成库存收货，采购发票直接选择已确认且验收通过的资产采购。
- 累计有效采购发票含税金额不得超过资产采购含税总额；尚未验收或已经足额收票时不能确认。
- 资产采购匹配不显示“正式入库”或“三单匹配”，但确认后沿用同一应付与付款事实。

## 5. 页面规格

- 列表固定显示：单号、来源、往来方、价税合计、已收/已付、未收/未付、经办人、到期日、拆分状态和下一步。
- 新建按钮位于全局顶部栏；应收/应付顶部提供“只看待收/待付”。
- 详情顶部栏放返回、打印、转 PDF、流转记录和当前唯一主动作。
- 金额区必须并列展示总额、已结金额和未结金额，避免从状态猜金额。
- 收付款使用专用弹窗，默认带出剩余金额，允许改为部分金额。
- 资金记录按事件时间展示，每笔包含唯一编号和外部资金凭证。
- 采购发票详情按来源显示三单匹配或资产采购匹配，并展示阻断原因、来源占用和剩余额度。

## 6. 原型边界

- 当前 JSON 服务验证单进程顺序、来源、数量、超额和幂等，不等价于正式会计系统。
- 正式实现需要数据库事务、行级锁或乐观锁、幂等唯一约束、银行流水对账、会计期间、总账凭证和权限复核。
- 本轮不伪造总账、成本核算、税务申报、银行自动对账或跨发票核销完成状态。

## 7. 本轮验收

- 发票生命周期与收付款进度已拆分展示。
- 应收、应付均支持部分收付款和逐笔资金记录。
- 采购发票确认前已接入行级三单匹配与正式入库拦截。
- 销售红冲、红字发票和退款关系继续保留。
- 列表已移除操作列，统一为整行进入详情。
- 财务专项烟测覆盖三单匹配、部分付款、幂等重试、付清、未入库拦截和部分收款。
