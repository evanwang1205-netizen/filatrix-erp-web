# Filatrix ERP 七模块逐页验收台账

本台账用于执行“逐页深检”，不代替蓝图与业务事实模型。蓝图和事实模型发生冲突时，以二者为准。

## 每个页面组的固定验收口径

一个页面组包含其列表、详情、新建、编辑以及相关工作台入口。只有同时完成以下项目才可标记为“已验收”：

1. 业务事实、字段来源、数量单位和关联对象正确；列表与详情取同一事实。
2. 主状态只表达生命周期；结果、履约/结算/质量/处置进度分别表达。
3. 当前责任、下一步动作、动作结果和不可操作原因清楚，流程可实际闭环。
4. 信息层级、卡片、表格、控件、长文本、空值、禁用态和错误态清晰且无重复噪音。
5. 与全系统页面语言一致；业务差异有明确理由，不为“统一”牺牲业务表达。
6. 通过桌面与窄屏检查、浏览器实际操作、相关审计/烟测和生产构建。
